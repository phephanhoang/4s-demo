# AI FOR WORK 02 · Bản minh họa

Bản HTML gồm 28 slide và 120 phút ghi chú giảng viên. Sáu ảnh minh họa và sáu sơ đồ bổ sung làm rõ các ví dụ và phần chuyển chương.

Chạy `python3 -m http.server 8000` trong thư mục này rồi mở http://localhost:8000/. Dùng ← / → để chuyển slide, Esc để mở mục lục và P để vào chế độ giảng viên.

Giữ thư mục `assets/` bên cạnh `index.html`. Trang dùng tài nguyên cục bộ. Các thay đổi trong phiên trình chiếu mất khi tải lại.
